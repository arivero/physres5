# Referee report round 1

## Central claim

The manuscript proposes that the Rivero--de Vries two-branch secular equation is a clue to an electroweak string/Kaluza-Klein spectral structure. The positive branch gives a number close to the W/Z pole-angle ratio. The negative branch points toward Higgs/order-parameter scales after vector-spectrum normalization.

## Strongest result

The draft now separates three objects cleanly:

- pole-spectrum ratio;
- electroweak projective datum from the gauge-Higgs mass matrix;
- string/Kaluza-Klein completion problem.

The strongest conceptual improvement is the relocation of \(J=3/4\) to the Higgs/order-parameter doublet side and \(J=2\) to the adjoint/current side.

## Main objections

1. **String/Kaluza-Klein mastery remains too compressed.**
   The bridge section lists real mechanisms but reads as a map. A PRD-length paper needs several sections deriving the relevance of Regge slopes, open-string endpoints, compactification charges, winding, moduli, and boundary spectra.

2. **The determinant still appears by assertion.**
   The matrix in Eq.~\eqref{eq:det-completion} needs one concrete toy model. A two-boundary interval model or two-channel endpoint model would be enough for a first derivation attempt.

3. **The negative branch needs arithmetic and scheme labels.**
   The section states the scales qualitatively. The paper should show the two scale formulas numerically using the seed normalization and then state which quantity each could map to.

4. **The pole-placement burden needs a diagram.**
   The reader needs a visual or table showing radical attachment options: pole condition, running parameter, GUT boundary value, KK eigenvalue, brane determinant.

5. **Source control is much better but page-level claims remain pending.**
   The fragment corpus exists. The next pass should page-check the claims used in the introduction and string/Kaluza-Klein section.

## Required revisions

- Split Sec.~\ref{sec:string-kk-g2} into at least three subsections in the next pass: Regge/dual models, KK compactification, boundary/brane mechanisms.
- Add a toy determinant derivation target in Lean-style notes.
- Add a short numerical table for the negative branch.
- Add a radical-placement table.
- Update the score table after implementation.
