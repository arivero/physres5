# Current-route no-prediction theorem -- 2026-05-25

## Scope

This note closes the current D8/O8 boundary-current route as a proof branch.
It does not classify all possible compactifications.  The assumptions are:

- the D10 carrier/probe geometry `M4 x CP2 x CP1`;
- the D8-like boundary carrier `W9=M4 x CP2 x S1_Q`;
- Payen endpoint variables and the current D8 DBI/WZ source package;
- endpoint spaces `H^0(CP1,O(2j))`;
- no added source content beyond the tested D8/O8, closed `H`, bare K-theory,
  and product O4/O6 routes;
- the current finite image/Hom and rotor candidates.

## Theorem

Under these assumptions, the D10 boundary-current construction does not force
the de Vries electroweak relation.  It supplies a coherent compatibility
framework, but at least one mandatory pass condition fails in each route that
would make the number predictive.

## Evidence by milestone

### Milestone 1

The finite Feshbach algebra gives the de Vries pole if the local action
contains the locked image-channel square.  A generic oscillator leaves
`r=gamma/alpha` free.  The mixed Hom field gives the right image field

```tex
Q_j=A_jy_j/\sqrt{J_j},
```

but the current Payen plus D8 DBI/WZ action does not supply the one-square Hom
term

```tex
||\sqrt{J_j}y_j-p_j||^2.
```

Thus the finite kernel is an allowed augmentation, not an output of the scoped
action.

### Milestone 2

Borel-Weil supplies the representations and Casimirs, but it gives a tower.
The finite set `j=0,1/2,1` is selected only after imposing a finite `SU(2)_2`
branch.  The rotor branch keeps higher states.

### Milestone 3

The canonical current metric gives `kappa_cur=1` on the full-current branch.
The horizontal branch gives

```tex
kappa_cur=0.7527390090748721,
\qquad
sin^2 theta_W=0.24226537471822063,
```

and fails the weak-angle target.  The current D8/Payen/RR package does not
select the full-current branch.

### Milestones 4 and 5

The bulk equations are two linear constraints on seven coefficients.  In the
reduced coefficient slice

```tex
B_H=B_0=B_2=B_6=0,
```

stationarity at any chosen `rho` is obtained from

```tex
B_4=B_R tau^2,
\qquad
B_loc=-(2/3)B_R tau rho^{-2}.
```

The selector terms have zero `rho,tau` derivatives on the selector branch.
The neutral scalar Hessian has enough coefficient freedom to fit

```tex
h_0^2=2J_v mu_B^2,
\qquad
M_h^2=J_H mu_B^2.
```

Thus the vacuum and scalar slice is a coefficient placement, not a prediction.

### Milestone 6

The current source package fails global source balance.  Endpoint data, closed
`H`, bare K-theory, and the tested product O4/O6 package do not cancel the
lower Bianchi classes.  The minimal repair is

```tex
Q_new=-h_Q^2,
```

but accepting it requires changed source content or topology, so it starts a
new compactification ansatz rather than completing the scoped branch.

### Milestone 7

The on-shell weak-angle number is close to the measured value, and the rotor
branch has a conditional `j=3/2` mass near `96.54 GeV`.  The scoped branch does
not compute threshold corrections, scheme conversion, production, branching,
or scalar running from a derived source/vacuum system.

## Consequence

The current route has a clean status:

```text
D10 boundary data are compatible with de Vries.
```

It does not establish:

```text
D10 boundary dynamics force de Vries.
```

The next branch, if pursued, must change the compactification ansatz before it
can claim source balance, vacuum coefficients, or scalar thresholds.
