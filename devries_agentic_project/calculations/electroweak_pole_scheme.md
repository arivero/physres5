# Analytical task: electroweak pole scheme

## Observable

The target observable is

\[
\sin^2\theta_{\rm pole}=1-\frac{M_{W,\rm pole}^2}{M_{Z,\rm pole}^2}.
\]

## Work items

1. Define the complex pole convention:
   \[
   s_V=M_{V,\rm pole}^2-iM_{V,\rm pole}\Gamma_{V,\rm pole}.
   \]
2. State the common Breit-Wigner convention and the conversion to pole mass.
3. Propagate uncertainties from \(M_Z\), \(M_W\), widths, and correlations.
4. Separate \(\sin^2\theta_{\rm pole}\) from \(\hat s^2(\mu)_{\overline{\rm MS}}\) and \(\sin^2\theta^{\ell}_{\rm eff}\).
5. Include a table with values used in the project and a future-proof data-update instruction.
