# Referee red team

Use this skill after major manuscript edits.

## Workflow

1. Read the manuscript and `OPEN_ISSUES.md`.
2. Identify strongest and weakest claims.
3. Separate fatal gaps from presentational gaps.
4. Propose concrete repairs.
5. Add falsification tests.

## Output

Create `reviews/referee_report_roundN.md` and `reviews/falsification_tests.md`.
