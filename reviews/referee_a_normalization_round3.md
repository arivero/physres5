# Referee A normalization round 3

## Central claim

The manuscript claims the DeVries positive-branch quotient should first be read
as a low-energy complex-pole W/Z observable,
\[
\sin^2\theta_{\rm pole}=1-\frac{M_{W,\rm pole}^2}{M_{Z,\rm pole}^2},
\]
with high-scale, running, effective-angle, and compactification readings
treated as separate translations.

## Strongest source-supported result

O2a is substantially improved. Sec. III defines the complex pole and uses the
Martin--Robertson vector-boson Breit--Wigner relation. The local source
fragment explicitly supports both the complex-pole definition and the statement
that quoted W/Z values are usually variable-width Breit--Wigner masses.

## Weakest inference

O8 remains the weakest step. Sec. VI.G states pole-scale attachment as the
proposed placement, and Appendix D correctly makes this a theorem target. The
manuscript still lacks a derived dynamical object whose eigenvalue condition is
naturally evaluated at the dressed W/Z pole.

## Hidden assumptions

The Breit--Wigner formula assumes the same pole parametrization used in the
source. The current text should specify whether \(\Gamma_{V,\rm pole}\) or a
quoted Breit--Wigner width enters each conversion. The pole-placement chain
also assumes the source kernel survives four-dimensional matching, thresholds,
and radiative corrections without changing the clean quotient.

## Exact revisions needed

In Sec. III, add the companion width convention and state the condition for
using
\[
M_{V,\rm BW}^2=M_{V,\rm pole}^2+\Gamma_{V,\rm pole}^2.
\]
In Sec. VI.G, label the three-arrow chain as an open matching theorem before
Eq. `eq:route-pole-ratio-target` is treated as physical placement. In Appendix
D, add the failure outcome: if the clean quotient is derived at a compactification
or unification scale, the pole comparison becomes a phenomenological clue and
the physical claim relocates to that scale.
