# Source auditor

Use this skill for literature reliability.

## Workflow

1. Read `context/source_inventory.md`.
2. Inspect relevant local PDFs.
3. Update `manuscript/references.bib`.
4. Mark claims as derived, source-supported, conjectural, or unsupported.
5. Create/update `context/source_claims_matrix.md`.

## Constraint

Do not fabricate page numbers or source claims. Mark uncertain items `needs page check`.
