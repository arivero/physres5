# Loop 16 Referee B: String, Kaluza--Klein, and Source Control

## Central Claim

The alpha and \(D=9\) \(U(1)\) endpoint idea should be downstream of the
source-reduction, ordered-assignment, pole-placement, scalar-map, and
dimensional-interpolation targets.  Physical status arrives only after those
targets produce a common source route.

## Strongest Source-Supported Result

Witten 1981 supports the endpoint hierarchy used by Appendix E:
seven compact dimensions can host an \(SU(3)\times SU(2)\times U(1)\) symmetry
in the class under discussion, and the same paper discusses an
\(SU(3)\times U(1)\) address in five compact dimensions.  Witten also supports
the broad KK statement that compact geometry controls gauge couplings through
the reduced Einstein action and metric data.

## Weakest Inference

The claim that a specific construction value lands at a specific low-energy
running electromagnetic coupling lacks primary-source control.  A
Kaluza--Klein \(U(1)\) coupling needs generator normalization, kinetic-term
normalization, charge lattice data, threshold data, and a convention for the
low-energy observable.

## Hidden Assumptions

1. \(v=\sqrt2M_-(2)\) is a physical, gauge-invariant scalar assignment.
2. The same \(\mu\) normalizes \(M_W\) from \(x_+(3/4)\) and \(v\) from \(x_-(2)\).
3. The negative \(J=2\) branch selects the radial Higgs datum.
4. The \(D=9\) endpoint \(U(1)\) is \(U(1)_{\rm em}\).
5. The compact \(U(1)\) coupling maps to low-energy QED through controlled thresholds.
6. The proposed scale placement uses a defined hadronic-vacuum-polarization scheme.
