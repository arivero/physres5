# DeVries manuscript architect

Use this skill when asked to plan, restructure, or expand the full manuscript.

## Workflow

1. Read `AGENTS.md`, `PROJECT_BRIEF.md`, `OPEN_ISSUES.md`, and `context/done_definition.md`.
2. Inspect `manuscript/main.tex` and section files.
3. Produce a section-level plan with page targets.
4. Keep derived, cited, conjectural, and open material separated.
5. Run `make manuscript` after structural edits.

## Output

Create a report in `reviews/architect_report.md` with the plan, page allocation, and next tasks.
