# Analytical task: Standard Model global form

## Object

The Standard Model local algebra is

\[
\mathfrak{su}(3)\oplus\mathfrak{su}(2)\oplus\mathfrak{u}(1).
\]

The global group can be

\[
G_{\rm SM}=\frac{SU(3)_C\times SU(2)_W\times U(1)_Y}{\Gamma},
\qquad \Gamma\subset\mathbb Z_6.
\]

## Manuscript role

This is a topological and line-operator appendix. It should not be used as the primary derivation of the DeVries mass ratio unless a concrete mechanism is added.

## Work items

1. Summarize the four possibilities \(\Gamma=1,\mathbb Z_2,\mathbb Z_3,\mathbb Z_6\).
2. State how line operators distinguish them.
3. State how theta-angle periodicities change.
4. Relate to possible topological transport tests.
5. Explain how this constrains any G2/Kaluza-Klein completion.
