\subsection{Minimum viable derivation}
\label{sec:minimum-viable-derivation}

A minimal derivation has five components:
\begin{equation}
  \mathcal S
  \longrightarrow
  \mathcal H_J
  \longrightarrow
  K_J(\lambda)
  \longrightarrow
  (J_H,J_{\rm adj})
  \longrightarrow
  (\sPole,\mathcal F_{\rm sc}).
  \label{eq:minimum-viable-derivation}
\end{equation}
The source theory \(\mathcal S\) may be a boundary effective action, an endpoint sector, or a localized \(G_2\) system.  The light subspace \(\mathcal H_J\) must contain an order-parameter channel and an adjoint/current channel.  The kernel \(K_J(\lambda)\) must reduce to the DeVries determinant in a stated normalization.  The ordered pair \((J_H,J_{\rm adj})=(3/4,2)\) must arise from gauge-Higgs or source-theory data.  The final arrow must attach the positive branch to the pole observable and the negative branch to a defined scalar functional.

The derivation therefore has a compact acceptance criterion:
\begin{equation}
  \det K_J(\lambda)=\lambda^2+J\lambda-J,
  \qquad
  (J_W,J_Z)=(3/4,2),
  \qquad
  u_-(J)\mapsto\mathcal F_{\rm sc}.
  \label{eq:acceptance-criterion}
\end{equation}
This criterion is deliberately demanding.  A partial result can still improve the manuscript by proving one arrow in Eq.~\eqref{eq:minimum-viable-derivation}.  For example, an interval model may derive the determinant class while leaving the pole placement open; an endpoint model may derive the ordered representation pair while leaving the scalar map open; a \(G_2\) model may supply a strong localization mechanism while leaving four-dimensional pole matching open.

\subsection{Referee-facing tests}
\label{sec:referee-facing-tests}

The paper can be evaluated by concrete tests:
\begin{enumerate}
\item The pole-scheme test: every W/Z comparison must use pole masses or give a conversion to pole quantities.
\item The assignment test: \(J=3/4\) must come from a doublet/order-parameter datum and \(J=2\) from an adjoint/current datum.
\item The determinant test: the source theory must produce the trace and determinant data of Eq.~\eqref{eq:det-completion}.
\item The scalar test: the negative branch must map to a defined scalar, boundary, brane, or deformation functional.
\item The ray test: the construction must respect the full electroweak broken-to-unbroken ray.
\item The global test: a compact completion must be compatible with Standard Model representations, line operators, and anomaly constraints.
\end{enumerate}
These tests are severe enough to make the speculative proposal useful.  They allow a route to be rejected cleanly.  They also allow a route to generate a broader secular family when the DeVries entries arise as a limit.
