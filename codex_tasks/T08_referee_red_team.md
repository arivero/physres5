# T08 — Referee and red-team review

## Goal

Find weaknesses before the final expansion.

## Instructions

1. Read the full manuscript.
2. Create `reviews/referee_report_round1.md` with:
   - strongest claims;
   - unsupported claims;
   - equations that require derivation;
   - likely referee objections;
   - concrete revisions.
3. Create `reviews/falsification_tests.md` with tests that can disconfirm the proposal.
4. Mark each manuscript section as derived, cited, conjectural, or open.
5. Do not rewrite the full manuscript in this task.

## Done when

The review files exist and include actionable revisions.
