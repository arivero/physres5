# Charge quantization check

## Question

The paired D-term boundary case works if new paired fields carry

```text
Y = +/- 3/8.
```

Can this charge be embedded naturally in the ordinary Standard Model or minimal
`SU(5)` charge lattice?

## Result

With the convention `Q=T_3+Y`, Standard Model hypercharges lie on a `1/6`
lattice:

```text
Y(Q_L)=1/6,
Y(u_R)=2/3,
Y(d_R)=-1/3,
Y(L)=-1/2,
Y(e_R)=-1,
Y(H)=1/2.
```

The proposed D-term charge gives

```text
(3/8)/(1/6) = 9/4,
```

so it is not on the usual `1/6` lattice.

For `SU(2)_L` singlets, the electric charges are

```text
Q = Y = +/- 3/8.
```

For low `SU(2)_L` multiplets with `Y=3/8`, the components also remain
fractionally charged in eighths, e.g.

```text
j=1/2: Q = -1/8, 7/8
j=1:   Q = -5/8, 3/8, 11/8
```

These are not ordinary integer or third-integer charge assignments.

## SU(5)

Minimal `SU(5)` hypercharge is generated by the fundamental entries
`-1/3` and `+1/2`, so ordinary `SU(5)` representations have hypercharges on
the same `1/6` Standard Model lattice.  Since `3/8` is not on that lattice, the
paired D-term charge is not naturally supplied by minimal `SU(5)`.

## Status

This does not make the paired D-term model inconsistent: scalars carry no gauge
anomalies, and vectorlike matter with opposite hypercharges can be anomaly-free.
But it makes the model exotic.  The `3/8` coefficient is not explained by
standard charge quantization; it is selected by hand.
