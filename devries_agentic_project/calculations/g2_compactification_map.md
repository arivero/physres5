# Analytical task: G2/M-theory bridge

## Baseline facts to source-audit

- Smooth compact G2 manifolds in M-theory yield four-dimensional \(N=1\) supersymmetry but only abelian gauge fields without charged chiral matter in the large smooth supergravity approximation.
- Nonabelian gauge symmetry and chiral matter require singularities.
- ADE codimension-four singularities support gauge sectors; isolated/conical singularities can support chiral fermions.

## Manuscript role

The G2 section should function as a controlled completion map:

1. which geometric structures can generate gauge sectors;
2. which structures localize chiral matter;
3. which structures could produce a two-branch mass secular equation;
4. which claims remain independent of generation counting.
